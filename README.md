# 💎 Diamonds Data Analysis

## 📌 Overview

An intermediate-level data analysis project built using **Python and Pandas**, focused on exploring and analyzing a real-world diamonds dataset containing **6,000 records**.

The project demonstrates practical data analysis and data preparation techniques while focusing entirely on **Pandas**.

## 🛠️ Technologies

* Python
* Pandas

## 📊 Dataset

The dataset contains information about diamonds, including:

* Carat
* Cut
* Color
* Clarity
* Depth
* Table
* Price
* Dimensions

## 🎯 Objective

The main goal of this project is to strengthen practical **Pandas** skills through real-world data analysis and prepare for more advanced Data Analyst projects.
